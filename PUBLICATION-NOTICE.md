# Public source repository boundaries

This repository publishes source and security guidance, not Digital Watchdog
proprietary installer binaries or licensed software. Runtime administrator
credentials, camera configuration, vendor packages and production data must
remain on the operator's Unraid server.

**Status: source release only; not yet a one-click or Community Apps install.**
The guarded private installation scripts require validation for each target
Unraid version and must not be run against an existing VMS deployment.

This repository is a clean public source snapshot. Historical development
branches, internal host names, lab addresses and operations notes remain in
a separate private engineering repository. No unattended updates or Docker
auto-restart are enabled.
